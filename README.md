## Data Quality & Limitations

Data quality was an important consideration throughout the analysis.

The assessment highlighted several areas requiring investigation:

- **Repeated customer IDs:** The dataset contained 508 rows and 500 distinct customer IDs. Record-level uniqueness and the handling of repeated IDs require clarification.
- **Missing values:** Some fields contained missing values that needed to be assessed before analysis.
- **KPI definitions:** The formulas, denominators, and filter context used for each KPI require validation.
- **Percentage formatting:** Percentage-based measures need consistent formatting and interpretation.
- **Customer behaviour classification:** The logic used to identify growing and declining customers requires validation against the underlying financial fields.
- **Result reconciliation:** Dashboard values should be checked against the source data and calculated measures.

These limitations demonstrate the importance of validating analytical results before using them to support business decisions.
